# Premium 3D Photographer Portfolio + Client Acquisition Platform

An editorial, cinematic photography portfolio and client acquisition platform featuring:
- **Cinematic Visual Experience**: Editorial layout, warm ivory on near-black palette, fluid typography.
- **Client Photo Management**: Zero-code image updates directly via Google Drive folders.
- **Subtle 3D Spatial Depth**: Three.js WebGL floating frames with progressive enhancement and fallbacks.
- **Client Acquisition Funnel**: High-conversion inquiry form with validation, rate limiting, and spam protection.
- **Production-Grade Engineering**: Next.js 15, React 19, TypeScript, WCAG 2.1 AA accessibility, and security hardening.

See [docs/architecture.md](docs/architecture.md) and [docs/design-system.md](docs/design-system.md) for full specifications.
